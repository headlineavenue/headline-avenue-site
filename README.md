# Headline Avenue

Official public website for Headline Avenue.

## Public pages
- `index.html` — homepage
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `data-deletion.html` — data deletion instructions
- `contact.html` — contact information

## Stack
Static HTML, CSS, and JavaScript. Designed for GitHub Pages with no build step.

## Deployment
Enable GitHub Pages for the `main` branch and repository root.

Expected site URL: `https://headlineavenue.github.io/headline-avenue-site/`
